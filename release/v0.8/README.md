# v0.8 · Windows

新号模板新增“首次登录”开关，默认关闭。开启后播放开场 CG 并自动进入第一关；需要配套 Android V0.1.3 或更新构建。打开已有存档、满级体验号不改变首登状态。

Adds an optional first-login opening sequence for newly created starter accounts. Off by default; requires Android V0.1.3 or later. Existing saves and experience accounts keep their login state.

解压后运行 `BH3-V1.9-Save-Editor-v0.8.exe`，无需安装 Python。35 项自动化测试及包含开关检查的 EXE 自检通过。
