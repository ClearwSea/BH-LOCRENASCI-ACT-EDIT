# v0.8.1 · Windows

首次登录仅在舰长等级为1时有效。新号改为其他等级时自动取消勾选并禁用，改回1级后可手动重新开启；保存时也会核对等级。

First login is available only at captain level 1. Changing a starter account to another level unchecks and disables it. Returning to level 1 allows manual re-enabling; saving also enforces the level requirement.

解压后运行 `BH3-V1.9-Save-Editor-v0.8.1.exe`。35 项自动化测试及包含等级联动检查的 EXE 自检通过。
