# BH3 V1.9 存档编辑器 · NS 使用方式

本工具在 Windows 上本地编辑兼容的离线 `account.json`。**v0.8.4 新增的深度编辑目录及剧情、外传、轮回、深渊规则针对 Android 的 BH2017-LOCRENASCI V0.2.0，尚未在 NS 验证。** 请先确认目标版本兼容，并保留独立原档；不要把 Android 的支持结论直接套用到 NS。

## 导出与导回

1. HOME → X 完全关闭游戏，仅回到 HOME 不够。
2. 使用已有的 DBI、FTP 或 SD 卡读取方式，将目标构建实际使用的存档复制到电脑并另存一份原档。历史默认路径如下，实际使用前须核对版本：

```text
sd:/switch/bh3_2017/server-stage3/data/account.json
```

3. 在电脑运行编辑器，打开副本。基础与深度编辑共用同一工作副本；预览后保存或另存。保存已有档时，源文件旁会留下带时间戳的 `.bak`；另存不能覆盖已有文件。昵称和签名只读。
4. 确认兼容后将文件以 `account.json` 名称放回实际位置，启动游戏核对、正常保存并重启验证。出现问题时关闭游戏，再恢复独立原档。

DBI 操作的是 SD 卡文件，不是系统存档导入；MTP 中的文件请先复制到电脑。新号“首次登录”在 NS 上的完整流程尚未验证，应保持关闭。有关 NS 构建和路径见 [NS 游戏指南](https://github.com/ClearwSea/BH-NX-Ferculum/blob/main/docs/agent-guide.md)。

轮回编辑会保留领奖回执，缺少必要记录时拒绝不安全的回退；不会为跳过内容直接发奖。不要假设编辑后已在 NS 完成领奖或游戏内验收。
