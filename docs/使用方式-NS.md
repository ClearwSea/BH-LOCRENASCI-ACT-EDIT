# BH3 V1.9存档修改器 · NS 使用方式

**登录账号和密码可随意输入，本地不设置检查。**

## 导出与放回

1. HOME → X 完全关闭游戏，仅回到 HOME 不够。
2. 用 DBI、FTP 或直连 SD 卡，将下列文件复制到电脑：

```text
sd:/switch/bh3_2017/server-stage3/data/account.json
```

3. 使用修改器编辑，再将文件放回原位置。
4. 重新启动游戏，检查结果。

使用 DBI 时操作的是 SD 卡文件，不是系统存档导入。MTP 中的文件请先复制到电脑再打开。

## 修改存档

双击 `BH3-V1.9-Save-Editor-v0.7.exe`，点击“打开存档”，选择拷到电脑上的 `account.json`。修改后可先点“预览修改”，再保存或另存。将输出文件以 `account.json` 名称放回原位置。

樱色轮回可选第一轮、第二轮、第三轮、第四轮 PART1，均从所选轮回开头继续。跳过的剧情不会直接发放奖励；回到已经完成的剧情重玩，可能再次获得剧情奖励，已有物品不会被扣除。轮回结算奖励的既有领取记录保留。

深渊“到达32关”表示第 32 关可挑战。请先在游戏中刷新本期深渊并结束战斗，再导出存档。

保存时会自动留下原文件备份。需要恢复时，关闭游戏及离线服务，把备份复制为 `account.json` 放回原目录即可。

仅支持此项目兼容的 V1.9 离线存档，不支持官方在线账号或任意同名 JSON 文件。部分表情会占用两个字符名额。

## 全通模板

“剧情关卡全部通关”：第 1–6 章普通剧情，共 189 关。

“外传关卡全部通关”：轩辕篇、蚩尤篇、永世回忆、卡莲幻想 VII，共 61 关。不含困难、噩梦、记忆战场或额外挑战。

采用旧演示存档的全通方式：通关和星级记录补齐，相关主线任务／外传成就设为已领取，不补发金币、水晶或物品。已有记录保留。不勾选则不修改该部分，并非清空已有进度。

## 深渊段位

可选择嚎叫、废土、禁忌、原罪、苦痛、红莲、无限七个段位，可与“到达32关”一起使用。保持现有楼层、道具和已领奖记录，不补发升段奖励。进入游戏后会按所选段位刷新温度和对手；旧段位的交互记录及最终层计时会清除。

请先在游戏中刷新本期深渊、结束战斗，再关闭游戏及服务端并导出存档。

## 内置账号模板

在顶部选择“新号”或“满级体验号”，点击“使用模板新建”，再点保存，选择一个尚不存在的文件名。模板不会自动覆盖正在编辑的旧存档。

- 新号：舰长与初始白练均1级，初始武器1级，无圣痕，剧情未通关；默认体力80，金币与水晶为0。
- 满级体验号：舰长及26位女武神80级，沿用演示档配装；主线189关、外传61关全通满星；樱色轮回从第四轮PART1开头继续。体力160，金币100000，水晶1000；46款皮肤、全角色满好感。
- 体验号装备包含当前已验证目录及演示档追加装备：534种武器、604种圣痕，均为各自品阶的满级。配装需要的同款副本保留。源表中已知不兼容／未纳入验证的装备不加入模板；不代表全部条目已完成战斗实测。
- 两个模板默认昵称“免费版本禁止倒卖”，签名“开源免费版本，仅供学习与技术交流，禁止倒卖，版权归米哈游所有”。

模板不包含旧账号的抽卡、充值、聊天和测试历史。签到、商店、深渊等周期状态在游戏中重新初始化。新号按现有离线版的登录方式进入，首次自动开场流程不额外强制开启。模板需要导回实际客户端验收。

使用内置账号模板时，昵称和签名在编辑器中只读；导出后重新打开仍保持只读。游戏内修改不受此限制，重新导入时会保留游戏内已有的昵称和签名。普通存档仍可编辑这两项。

舰长等级可修改为 1–80 级。变更等级时，当前等级经验归零，不补发升级奖励；角色等级、装备、现有体力和关卡进度保持原值。等级不变则保留原经验。降低等级可能使部分功能暂时不满足开放条件。
