# BH3 V1.9 存档编辑器 · Android 使用方式

本工具在 Windows 上本地编辑兼容的离线 `account.json`。深度编辑目录和剧情、外传、轮回、深渊规则以 **BH2017-LOCRENASCI V0.2.0** 为准；旧版 Android 和其他分支尚未验证本次扩展。

## 导出与导回

1. 在游戏启动页导出当前存档，并将其复制到电脑；保留一份独立原档。退出游戏和本地服务端。
2. 运行 Windows 单文件编辑器，打开电脑上的存档，或从新号、满级体验号模板创建。已有档的昵称和签名在编辑器中只读。
3. 在基础或“深度编辑”页调整，两处共用同一工作副本。预览累计修改后保存或另存。已有档保存前会在源文件旁留下带时间戳的 `.bak`；另存不能覆盖已有文件。
4. 将修改后的文件传回手机，在启动页选择存档，再点击开始游戏。**V0.2.0 会直接导入所选文件，不自动备份此前的当前档。**
5. 进入游戏核对修改、正常保存并重启检查。需要恢复时，退出游戏并选择先前导出的独立原档或电脑上的备份。

应用私有目录通常不能通过普通 USB 文件传输访问。旧版或独立服务端请核对实际包名与存档路径；电脑运行的服务端应编辑其实际使用的存档。有关游戏启动页见 [Android 游戏指南](https://github.com/ClearwSea/BH2017-LOCRENASCI/blob/main/docs/agent-guide.md)。

## 编辑范围

深度编辑包含舰长资源、女武神及技能、服装、武器和圣痕实例、材料、剧情与外传、轮回与深渊以及部分家园舱室；详见[项目说明](../README.md)。家园科技只读，圣痕词缀暂不编辑。

关卡可按难度、章节及具体关卡选择，也可设置支持关卡满星；不构造虚假战斗结算。轮回可选择具体剧情，保留已有领奖回执，缺少必要回执时会拒绝不安全的回退；不会为跳过内容直接发奖。深渊需要先在游戏中解锁并刷新本期状态，再结束战斗、退出并导出。

新号和满级体验号使用 V0.2.0 目录生成，不包含旧账号的抽卡、充值或聊天历史。模板和各类编辑完成保存后仍需导回实际客户端验证，不表示所有内容均已实机验收。
