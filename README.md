# BH-LOCRENASCI-ACT-EDIT

**BH3 V1.9 存档修改器 v0.8.4**，一个使用 Python / Tkinter 编写的离线存档编辑工具。

在 Windows 上本地编辑兼容格式的 `account.json`。可以打开已有存档或从模板新建，在同一工作副本中调整、预览并保存。

深度编辑目录及剧情、外传、樱色轮回与深渊规则对应 **BH2017-LOCRENASCI V0.2.0**。旧版 Android、NS 和其他分支尚未针对本次扩展验证；请先保留原档并确认目标版本兼容。保存成功不等于游戏内验收。

## 可以修改什么

- 舰长等级、金币、水晶、体力、友情点、技能点及其上限、装备容量；昵称与签名只读，请在游戏内修改。
- 按女武神查看和调整解锁、评阶、等级、好感、碎片及技能等级。
- 逐套解锁、锁定及切换服装；搜索并调整武器、圣痕实例与穿戴关系；按名称、类型或 ID 搜索材料并调整数量，或批量补充常用材料。圣痕词缀暂不编辑。
- 在剧情或外传中按难度、章节和关卡选择解锁目标，并对章节或全部支持关卡设置满星；选择樱色轮回具体剧情，以及深渊段位和目标层。
- 查看并提升已支持的 3、4、5 号舱室等级与扩建；科技只读。

等级变化时当前等级经验归零，并检查角色和舱室约束。深渊编辑需要有效的当期深渊状态；旧式角色碎片、缺失的轮回领奖回执或进行中的战斗可能阻止安全编辑。轮回编辑保留领奖回执，缺少必要记录时不能回退。

## 内置账号模板

- **新号**：舰长、初始白练及初始武器为 1 级；可按界面选择首次登录。
- **满级体验号**：基于 V0.2.0 目录解锁角色、服装并设置支持关卡满星，不代表所有装备、剧情或活动均已实机验证。

所有存档的昵称与签名均在编辑器内只读；游戏内修改不受此限制。

## 保存方式

关闭游戏及本地服务端，将导出的存档复制到电脑再打开。基础和深度编辑操作共享同一个工作副本，点击“预览修改”核对累计改动后保存或另存。

保存已有文件前，编辑器在源文件旁创建带时间戳的 `.bak` 备份，并检查原文件是否被外部修改；另存或新建不能覆盖已有目标。导回游戏前也应保留独立原档。Android V0.2.0 启动页更换存档时会直接导入，**不会自动备份被替换的当前档**；需要保留进度时请先导出。

## 开发与贡献

运行只依赖 Python 标准库及 Tcl/Tk；Windows 构建为单文件 EXE。测试、打包及精简目录的来源与重建方式见[源码说明](docs/README.md)和[目录来源](docs/editor-catalog.md)。欢迎使用去除个人数据的最小样例说明兼容问题；不要提交真实账号、密钥或游戏安装包。

本工具仅处理已探明的字段，不以开放所有存档字段为目标。支持范围是兼容的 V1.9 离线存档，不支持官方在线账号。
