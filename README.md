# BH-LOCRENASCI-ACT-EDIT

**BH3 V1.9 存档修改器**，一个使用 Python / Tkinter 编写的离线存档编辑工具。

在 Windows 上编辑兼容格式的 `account.json`，适用于本项目 Android 与 NS 离线版本。读取文件、预览改动、保存或另存，全程在本地完成。

## 可以修改什么

- 舰长等级（1–80）、金币、水晶、体力、友情点。
- 普通存档的昵称与签名。
- 樱色轮回：第一轮至第四轮 PART1，从所选轮回开头继续。
- 剧情与外传全部通关满星，相关任务按已领取处理，不补发奖励。
- 深渊到达第 32 关，以及七个段位选择。

等级变化时当前等级经验归零；角色与装备等级不会随之改变。深渊编辑需要有效的当期深渊状态。

## 内置账号模板

- **新号**：舰长、初始白练及初始武器均为 1 级。
- **满级体验号**：舰长及 26 位女武神 80 级，剧情与外传满星，樱色轮回第四轮 PART1，已验证装备目录、皮肤与满好感；默认体力 160、10 万金币、1000 水晶。

两个模板的昵称与签名在编辑器内只读，重新打开模板档仍保留限制。游戏内修改不受限制。模板并非完整游戏数据，装备覆盖范围见使用说明。

## 保存方式

已有文件保存前自动备份，检测原文件是否被外部修改；新模板仅创建新文件。请将导出的文件以 `account.json` 名称导回对应版本的存档目录。

## 开发与贡献

运行只依赖 Python 标准库及 Tcl/Tk。当前版本附 35 项自动化测试。欢迎通过最小化、去除个人数据的样例说明兼容问题；不要提交真实账号、密钥或游戏安装包。

本工具仅处理已探明的字段，不以开放所有存档字段为目标。支持范围是兼容的 V1.9 离线存档，不支持官方在线账号。
